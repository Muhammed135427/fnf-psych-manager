# FNF Psych Engine 1.0.4 - C# Mod & Proje Yönetim Aracı

Bu proje, **Friday Night Funkin' Psych Engine 1.0.4** sürümüne ait mod dosyalarını, karakter verilerini, şarkı chart'larını ve Lua betiklerini yönetmek amacıyla C# ve Visual Studio ortamında geliştirilmiş bir masaüstü uygulamasıdır.

## 🚀 Özellikler
- **Proje Yönetimi:** Psych Engine mod klasörünü seçme ve yapılandırma.
- **Karakter Düzenleyici:** `.xml` ve `.json` formatındaki karakter verilerini okuma ve güncelleme.
- **Chart Analiz:** Şarkı nota verilerini ve BPM bilgilerini listeleme.
- **Veritabanı Entegrasyonu:** Proje ve kullanıcı tercihlerini MySQL/SQLite veritabanında saklama.

## 🛠️ Teknolojiler
- **Dil:** C#
- **Geliştirme Ortamı:** Visual Studio 2022
- **Arayüz:** Windows Forms / WPF
- **Veritabanı:** MySQL
